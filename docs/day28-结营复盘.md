## 28 天里我最大的一个认知改变

**AI 真的给了我们普通人一个很新的机会——能够让我们在什么都不懂的情况下，从零到有，把自己的念头落地。**

这真的是一个很伟大的时代。你的每一个想象，每一项灵感，甚至每一个念头，都有可能被你自己亲手实现。

28 天前，「我自己做一个产品」这件事对我来说是别人的故事。今天它是一个能打开的网址、一个真的有人（包括我自己和朋友）在用的课表工具。中间没有天赋异禀，就是一天一步，按部就班。

所以我的结论是：**无论以后工作要不要用到 AI，都应该花一点时间去了解它，稍微学习一下它，它真的能极大提高你的效率。** 我敢说，AI 给我们普通人带来的机会，一定是所有机会里面最容易抓住的，而且是最有发展前景的。

- **第 1–14 天**：原生 HTML/CSS/JS 把前端立起来，本地数据先跑通——先让它「能用」。
- **第 15–24 天**：上 CloudBase 后端，PostgreSQL 两张表 + 增删改查接口闭环，中间踩了「本地验证 ≠ 公网生效」「嵌套插入不支持」这些真坑——先让它「真的在线上活着」。
- **第 25 天**：爆发日。导入教务课表、课表口令多用户、周视图换周、设置页、.ics 导出，MVP 十项全落地。
- **第 26–27 天**：发布 v1.0、真实回滚演练（28 秒回滚）、微信场景断链修复、资源到期排查——先让它「坏了也知道怎么救」。
- **第 28 天（今天）**：十项验收全 PASS、292 条回归断言全绿，作品 v1.0 结营。
