# WG课程表

给大学生用的手机网页课表：**点一下桌面图标，马上看到「今天第几节、上什么课、在哪上、开始了没」**。没有广告，不用注册，不用下载 App。

> 个人学习项目。这是参加 Vibe Coding 训练营的实际作品，从需求研究做到 PRD，再一步步开发上线。

## 为什么做这个

教务系统能用但不好用：给的是整学期的表，要自己心算「现在第几周、今天星期几」。而真正的需求发生在最后一刻——**人已经走到教学楼门口，要的是「现在这一节在哪」**，不是一张需要解读的表格。

现有的课表 App 要么太重（下载、注册、看广告、面对一堆和课表无关的模块），要么受平台限制拿不到课表数据。

## 要做的

一个用手机浏览器打开、可「添加到手机主屏幕」的个人课表：

- **首页就是答案页** —— 当前第几周 + 今天日期 + 今日课程，每节课标出「已结束 / 正在上课 / 未开始」，顶部固定显示「下一节课」
- **导入即用** —— 直接解析教务系统导出的课表文件，不做识别、不用联网登录，准确率 100%
- **数据只在自己手机上** —— 存在浏览器本机，不上传服务器；提供备份导出，换手机不丢
- **导进系统日历** —— 一键导出 `.ics`，白拿系统日历的桌面小组件和课前提醒

## 技术形态

先做**网页（PWA）**：手机浏览器打开 → 添加到主屏幕 → 得到一个全屏独立窗口的图标，点开即见课表。

选这条路的原因：零注册、零备案、成本最低、覆盖机型最广。微信小程序作为后续可选外壳（课表计算与渲染逻辑可复用）。
